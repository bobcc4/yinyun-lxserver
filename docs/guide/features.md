# 全部功能

本页是 V1 当前用户功能的索引。具体操作与限制请进入对应专题。

![Web 播放器搜索与播放界面](/screenshots/web-search.png)

当前 V1 Web 播放器同时面向在线搜索、歌单、本地曲库和服务器下载场景。

## 部署与运行

- Docker、Docker Compose、源码和 Release 压缩包部署。
- Windows、macOS、Linux 桌面客户端，支持安装版与便携版。
- Windows x64、x86、ARM64，macOS Intel、Apple Silicon，Linux amd64、ARM64。
- 桌面端托盘常驻、启动等待、端口冲突处理、存储目录选择及迁移。
- 管理后台与 Web 播放器路径可分别配置，支持反向代理。
- `/data`、`/logs`、`/cache`、`/music` 独立持久化。

详见：[快速开始](/guide/getting-started)、[桌面客户端](/guide/desktop)、[配置指南](/guide/configuration)。

## 账户、同步与安全

- 管理员后台密码与普通同步账户分离。
- 多用户创建、改名、改密、删除和管理员身份标识。
- 用户名统一按小写处理，登录时不区分大小写。
- Windows 客户端加密账户快照、显式恢复和便携备份导入导出。
- 管理后台密码与同步账户分离，用户数据按账户隔离。
- 登录会话与长期 Token 管理，支持启停、期限和访问记录。
- 用户数据、设置、自定义源及曲库目录按账户隔离。

详见：[账户与 Windows 同步](/guide/accounts-sync)、[管理后台](/guide/sync-server)。

## 搜索、浏览与收藏

- 支持 `wy`、`tx`、`kw`、`kg`、`mg` 多平台搜索与聚合结果。
- 热搜、搜索建议、排行榜、推荐歌单和歌单详情。
- 歌曲、专辑、歌手搜索；歌手热门歌曲、最新歌曲和全部专辑。
- 收藏歌曲、歌单、歌手和专辑。
- 在专辑列表直接下载整张专辑，也可在详情中批量播放或下载。
- 自定义歌单创建、重命名、删除；批量把已绑定平台 ID 的本地歌曲加入歌单。
- 播放队列拖拽排序、定位当前歌曲、批量管理和播放模式切换。

## 播放、歌词与显示

- 播放、暂停、上一曲、下一曲、进度、音量、倍速和睡眠定时。
- 顺序播放、列表循环、单曲循环和随机播放。
- 默认无损音质，并支持逐曲自动降级与失败换源。
- 音质范围：标准、高音质、无损、24bit 无损、Hi-Res、空间音频、增强空间音频、母带。
- 原文歌词、翻译、罗马音、逐字歌词、字体和字号设置。
- 下载时保存外置歌词并在支持的音频容器中嵌入歌词。
- 封面读取、下载和音频标签嵌入；歌词卡片生成与分享。
- 多主题、深浅色模式、音频可视化、均衡器与音效、淡入淡出。
- Media Session 与系统媒体控制，支持锁屏信息和进度控制。
- PWA、移动网页适配、自动恢复播放进度。

详见：[Web 播放器](/guide/web-player)。

## 下载、缓存与本地曲库

- 浏览器下载和下载到服务器两种模式。
- 单曲、批量、歌单和整张专辑下载。
- 下载前探测各音质真实大小及实际解析平台。
- 服务器下载队列持久化：关闭浏览器后继续下载，重新打开后恢复队列。
- 使用用户设置的并发数，支持全部继续、暂停、重试和失败换源。
- 下载文件写入封面、歌词、歌曲名、歌手、专辑、音质和平台来源等元数据。
- 可配置文件命名，默认简洁格式为“歌名 - 歌手 - 音质 - 专辑名”。
- `/cache` 播放缓存与 `/music` 下载曲库分离，清理缓存不会删除下载目录。
- 扫描 `/music` 下多层目录，读取用户自行放入的音频文件。
- 本地歌曲分页、排序、音质与状态筛选、批量选择和布尔搜索。
- 批量重命名、更新元数据、补全封面、补全歌词、嵌入歌词和删除。
- 检测缺封面、缺歌词、无平台 ID 等状态。

详见：[本地曲库与下载](/guide/library-downloads)。

## 歌曲洗版

- 在设置中启用后，对 `/music` 下载目录中的选中歌曲执行洗版，不处理 `/cache`。
- 支持按歌名、歌手、专辑搜索后选择歌曲。
- 可将高音质改为较低目标音质，也可尝试从低音质升级。
- 目标不可用时按规则降级，并在结果中记录实际音质与失败原因。
- 保留原文件封面、歌词和主要元数据；成功后替换原文件。
- 查看成功、失败、跳过的具体歌曲，支持取消正在进行的任务。

详见：[歌曲洗版](/guide/remaster)。

## 自定义源、代理与分享

- 自定义源 JS 文件上传、URL 导入、启停、排序、删除和校验。
- 自定义源属于当前登录账户，支持安全沙箱；原生 VM 兼容模式默认关闭。
- 全局外发代理、播放代理与下载代理可按网络环境配置。
- 管理员可以把完整音源共享给指定普通用户并随时撤销；每个用户可独立选择每个自有或共享音源启用的平台。
- 用户开启歌单分享后，可以向同样允许接收的用户发送歌单邀请。
- 接收方明确接受后才加入收藏；拒绝不会写入歌单。
- 音云服务端之间可以通过带有效期的链接或 JSON 分享歌单，接收方确认预览后创建普通歌单；本地歌曲优先匹配，不复制音频文件。
- 分享包不包含密码、Token、代理、本地路径或临时播放地址；不提供原版洛雪客户端的 `lxmusic://` / `.lxmc` 导入兼容。

详见：[自定义音源](/guide/custom-sources)、[歌单与音源分享](/guide/sharing)。

## Subsonic 客户端

- 兼容音流、LMP、Feishin 等 Subsonic/OpenSubsonic 客户端。
- 提供歌单、歌曲、专辑、歌手、封面、歌词、流媒体、随机歌曲等接口。
- 本地曲库与在线搜索，支持 `tx:`、`wy:`、`kw:`、`kg:`、`mg:` 前缀。
- 支持 `online:` 强制在线搜索，`local:` 强制本地搜索。
- 支持回退、合并和仅本地三种搜索模式。
- 可向客户端返回翻译歌词，并支持 Range 流式播放和缓存复用。

详见：[Subsonic 客户端](/guide/subsonic)。

## 管理、备份与维护

- 仪表盘、用户与管理员标识。
- 查看和管理用户歌单、歌曲数据及历史快照。
- 系统配置可视化编辑、连接测试和运行日志查看。
- WebDAV 增量同步、全量备份、手动上传与恢复。
- 在线文件管理、下载、上传、重命名、压缩与解压。
- 缓存容量限制与 LRU 清理。
- 版本检查、服务健康状态和匿名统计关闭选项。

详见：[管理后台](/guide/sync-server)、[备份与数据目录](/guide/storage-backup)、[故障排查](/guide/troubleshooting)。
